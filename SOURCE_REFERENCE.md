# Upstream reference

The project design was informed by the public `TaherehZarratEhsan/Chicken-Behavior-Analysis` repository and its README. The upstream README describes a pipeline for chicken detection, tracking, and trajectory-based behavior analysis; it instructs users to train YOLOv4 on the provided YOLO-format dataset or their own annotations, then use the trained model for detection/tracking. The prototype here is a fresh FastAPI implementation and does not bundle upstream code or claim the upstream trained weights are complete/loadable.

Reference: https://github.com/TaherehZarratEhsan/Chicken-Behavior-Analysis
Paper: https://arxiv.org/abs/2401.12176
